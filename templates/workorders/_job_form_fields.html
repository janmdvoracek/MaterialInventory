{% comment %} The body of the Zpracování form: the job's own fields, then one block per `JOB_SECTIONS` entry (`sections` in the context, from `_job_context`). Shared by transform_form.html (recording a job) and job_edit.html (a manager correcting one), so a field added to a row cannot land on one page and be forgotten on the other. Rendered inside the caller's own
, so there is no tag, no {% csrf_token %} and no primary submit button here — those differ per page and stay with the caller. Because the browser submits a form via its *first* submit button when Enter is pressed, and the row buttons below come before the caller's real one, each caller opens its with an off-screen decoy submit so Enter still saves. Each section's two row buttons are plain submits posting the form back under `add_` or `remove_`; the view rebuilds the page unbound one row bigger or smaller (`_job_forms`). There is no JavaScript in this app. Both carry `formnovalidate`, or the browser would refuse to submit a half-filled form and the buttons would silently do nothing. „− odebrat řádek" is hidden once a section is down to one row; the view holds the same floor regardless, so hiding it is presentation, not the rule. „Zapsat za" is guarded because it is manager-only: `job_edit` builds `WorkOrderForm` without a `user`, so the field is not there. The hours label comes from the form, because each page means something different by it. **Every error this page can produce is rendered, and that is a rule rather than a nicety.** Nothing is written unless all five forms validate, so an error with nowhere to appear is a submission that vanishes: the page comes back carrying what was typed, with no message anywhere, looking as if the button had not been pressed. {% endcomment %} {% for error in order_form.non_field_errors %}
